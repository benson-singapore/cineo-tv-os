# Nova TV 开发文档

这里维护 Nova TV 客户端的开发计划、待确认事项和决策记录。产品范围与技术基线来自用户提供的《Nova TV — 产品需求文档与技术架构设计 V1.0》。

## 文档

| 文档 | 用途 |
|---|---|
| [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md) | MVP 范围、阶段顺序、任务清单、依赖关系和阶段验收条件 |
| [DECISIONS.md](./DECISIONS.md) | 开发前及联调前需要确认的设备、API、授权与账号事项 |

## 当前状态

- **整体状态：** 尚未开始；项目目录目前没有应用源码。
- **当前阶段：** 阶段 0 — 确认基础条件并建立工程。
- **建议下一步：** 确认 Android Studio / SDK 环境和目标当贝设备信息，然后创建可在 Android TV 模拟器启动的最小 Compose for TV 工程。
- **计划方式：** 按依赖和可验收产出推进，不预设日期或工期；有负责人和时间安排后再补入。

## 更新约定

1. 开始任务时，将对应项从 `[ ]` 改为 `[/]`，完成后改为 `[x]`。
2. 遇到外部依赖时，在任务项写明阻塞原因，并链接到 `DECISIONS.md` 中对应事项。
3. 阶段完成后，确认阶段验收条件全部满足，再推进下一阶段。
4. 需求范围变化时，先更新 MVP 范围和任务清单，再开始实现。
