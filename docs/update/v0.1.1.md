# Cineo TV OS v0.1.1

## 版本

- 版本号：v0.1.1；versionCode：2
- 发布时间：计划于 2026-11-20，实际时间以 GitHub Release 为准。
- 上一版本：v0.1.0
- 覆盖范围：`v0.1.0..b4541c3`

## 概述

新增 Hub 云端同步和 Orbit 插件支持，并提供手机协助电视搜索输入、连续播放及电视导航改进。

## 新功能

- 绑定 Cineo Hub 并同步设备数据。
- 浏览和播放 Orbit 插件内容，显示插件信息并独立记录 Orbit 观看历史。
- 普通搜索和 Orbit 搜索支持接收手机提交的文本，仍由电视端确认搜索。
- 支持下一集发现与预加载，显示观看完成状态。

## 变更与优化

- 改进插件选择、封面展示、分页加载和焦点导航。
- 调整播放进度保存及遥控器输入体验。

## 修复

- 兼容无游标偏移分页、部分 Orbit 加密封面和图片域名。
- 区分 Hub 设备凭证失效与上游认证错误，避免错误撤销绑定。
- 支持方向键连续快进快退，修复设置与云端同步焦点问题。

## 构建与发布说明

计划由 GitHub Actions 构建签名 APK `CineoTV-v0.1.1.apk`，实际结果以工作流为准。可使用 `adb install -r CineoTV-v0.1.1.apk` 安装；若旧版签名不同，卸载旧版会清除本地数据。
