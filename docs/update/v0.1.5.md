# v0.1.5

## 版本

- 计划发布日期：2026-11-28
- 上一版本：v0.1.4
- 覆盖范围：`v0.1.4..v0.1.5`

## 概述

本版本完善 Orbit 访问设置、云同步绑定隔离及播放器遥控操作。

## 新功能与优化

- 增加 Orbit 总开关、单插件开关、密码及可配置的免验证时间，缓存插件列表和能力信息。
- 绑定切换时隔离旧待同步数据和云端设置，避免将身份不明的记录自动上传到新账号。
- 优化 Orbit 设置弹窗和遥控焦点路径，保留独立播放历史。
- Hub 断线时插件仍需要 Hub 执行；缓存不包含插件运行程序。

## 修复

- 改善播放时确认、方向键及上一集、下一集操作。

## 构建与发布说明

- GitHub Actions 预期构建签名 APK `CineoTV-v0.1.5.apk`，具体结果以流水线为准。
- 本日志随版本提交，并作为 GitHub Release 正文。
