# v0.1.3

## 版本

- 版本号：v0.1.3
- 发布时间：2026-11-21
- 上一版本：v0.1.2
- 覆盖范围：`v0.1.2..v0.1.3`

## 概述

本版本完善 Orbit 浏览、播放和插件设置，改进电视端播放历史同步，并加入版本更新提示。

## 新功能

- 启动时检查电视应用版本并提示下载；视频卡片展示剧集信息。
- Orbit 支持二级筛选、详情接口直接播放，以及记住插件选择和独立预览设置。
- 完善 Orbit 选集和播放返回确认。

## 修复

- 修复电视端进度同步与历史重建，播放进度附带年份和分类。
- 仅在全新安装时初始化默认视频源，并调整主菜单默认显示。
- 修复 Orbit 选集卡片封面、黄果爱作品评分和集数显示，改善详情标题布局。

## 其他变更

- 增加隔离 Hub 同步和电视历史快照对账相关测试。

## 构建与发布说明

- 产物：GitHub Actions 构建的签名 APK `CineoTV-v0.1.3.apk`；最低 Android API 级别为 28。
- 安装：电视开启 ADB 调试后执行 `adb install -r CineoTV-v0.1.3.apk`。
- 如旧版由不同密钥签名，需先卸载旧版；卸载会清除应用本地数据。
- 本日志在打标签前提交，实际构建结果以 GitHub Actions 为准。
