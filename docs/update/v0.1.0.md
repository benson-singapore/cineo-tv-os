# v0.1.0

## 版本

- 版本号：v0.1.0
- 发布时间：2026-11-08
- 上一版本：首次发布
- 覆盖范围：`v0.1.0` 可达的全部历史

## 概述

Cineo TV OS 首个版本。面向 Android TV 的影视浏览与播放客户端，包含首页、分类浏览、影片详情、剧集选择、视频源配置与播放能力，并接入本地存储、MacCMS 视频源与 TMDB 元数据。同时建立签名 APK 的 GitHub Actions 发布流水线。

## 新功能

- 搭建 Android TV 首页与遥控器焦点交互原型（`d5f06fa`），并重构首页视觉、增加退出确认流程（`5ec6da6`）。
- 新增本地存储、MacCMS 视频源与 TMDB 元数据层（`8bc20ae`）。
- 接入网络视频浏览、详情播放与视频源配置界面（`eb4bc92`）。
- 在浏览界面展示 TMDB 缓存元数据（`d6d56f8`）。
- 增加 GitHub Actions 签名 APK 发布流水线，支持 tag 触发与手动触发（`09b9f48`）。
- 添加 Cineo TV 发布与更新日志技能，规范版本、日志与发布验证流程（`ad17d12`）。

## 变更与优化

- 将视频标题显示逻辑移入播放器，并关联控制器可见性（`bea68b9`）。

## 修复

- 修复切换分类时网格滚动位置重置问题（`586f3e7`）。
- 修复分类切换后列表滚动位置与协程取消处理（`60c1a7b`）。
- 将影片搜索限定到当前默认视频源，避免聚合多站点时的不可用提示（`ff91bd5`）。

## 文档与维护

- 添加 Nova TV 开发计划与决策记录（`1c744ec`）。
- 增加设备互联与多端同步设计文档（`ee362e3`）。
- 重命名品牌并完善项目文档（`812178b`）。
- 在 README 中增加界面预览截图（`5f2532b`）。

## 构建与发布说明

- 产物：GitHub Actions 构建的签名 APK `CineoTV-v0.1.0.apk`
- 安装：电视开启 ADB 调试后执行 `adb install -r CineoTV-v0.1.0.apk`
- 如旧版由不同签名密钥安装，需先 `adb uninstall com.nova.tv`
- 本日志在打 tag 前提交，GitHub Actions 直接读取本文件作为 Release 正文
- 具体构建结果以本次 GitHub Actions run 为准
